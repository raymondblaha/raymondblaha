## Featured Project

### [Envirohealth Pipeline](https://github.com/raymondblaha/Envirohealth-pipeline)

A reproducible Python/PostgreSQL data engineering and analytics project integrating EPA air quality data with CDC PLACES county health indicators.

This project demonstrates:

- PostgreSQL `raw -> core -> analytics` database design
- SQL schema creation, transformations, analytical views, and validation checks
- Python package structure with reusable ETL, profiling, analysis, and modeling modules
- Docker Compose for local PostgreSQL
- GitHub Actions CI with linting, tests, database integration tests, and Docker build
- Statistical analysis and machine learning benchmarks with documented limitations
